# Código de conduta

Queremos um espaço útil para quem instala, usa e contribui com o Dokke.

Esperamos comunicação objetiva, respeito por pessoas com níveis diferentes de experiência e críticas sobre o código — nunca ataques pessoais, assédio ou discriminação.

Conteúdo abusivo pode ser reportado aos mantenedores por uma Discussion privada ou pelo perfil do projeto. Podemos remover comentários, encerrar discussões e bloquear participantes quando necessário para manter a comunidade segura.
