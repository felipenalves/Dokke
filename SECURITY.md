# Segurança

O Dokke foi feito para funcionar na rede local. Não publique PINs, keystores, senhas, tokens ou detalhes que permitam acessar uma instalação real.

Se você encontrar uma vulnerabilidade, não abra uma Issue pública. Use um [Security Advisory privado](https://github.com/felipenalves/Dokke/security/advisories/new) ou entre em contato pelo perfil do mantenedor no GitHub. Inclua passos para reproduzir, impacto e uma correção sugerida se tiver uma.

Issues e Discussions são para bugs e dúvidas sem dados sensíveis.
